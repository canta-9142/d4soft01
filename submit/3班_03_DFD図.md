## レベル0ダイアグラム

```mermaid
flowchart LR
    U[利用者]
    P0([0 キャンバス型ToDoアプリ])
    D4[(D4 localStorage)]

    U -->|アプリの起動、キャンバス・タスク・接続の操作<br/>表示条件、履歴、保存・復元の指示| P0
    P0 -->|キャンバス画面、タスク、接続線<br/>状態表示、操作結果、エラー| U
    P0 -->|検証済みアプリ状態のJSON| D4
    D4 -->|保存済みアプリ状態のJSON| P0
```

## レベル1ダイアグラム

レベル0のプロセス0を主要機能に分解する。D1からD3はメモリー上のデータ、D4はブラウザー内の永続データである。

```mermaid
flowchart TB
    U[利用者]

    P1([1.0 操作を受け付け<br/>画面を描画する])
    P2([2.0 キャンバスを管理する])
    P3([3.0 タスクを管理する])
    P4([4.0 接続を管理する])
    P5([5.0 表示対象を<br/>絞り込む])
    P6([6.0 操作履歴を管理する])
    P7([7.0 状態を保存・復元する])

    D1[(D1 実行中アプリ状態<br/>Application・AppState)]
    D2[(D2 コピー状態<br/>ClipboardState)]
    D3[(D3 undo・redo履歴<br/>最大50件)]
    D4[(D4 localStorage)]

    U -->|マウス・キーボード操作、入力値| P1
    P1 -->|描画結果、状態、エラー| U

    P1 -->|作成、切替、名称変更<br/>パン、削除の指示| P2
    P2 -->|処理結果| P1
    P2 <-->|キャンバス、現在キャンバスID<br/>表示位置、表示設定| D1
    P2 -->|キャンバス削除の変更記録| P6
    P2 -->|切り替え時の保存要求| P7

    P1 -->|登録、選択、編集、移動<br/>コピー、貼付、削除の指示| P3
    P3 -->|処理結果、選択状態| P1
    P3 <-->|タスク、選択状態、表示設定| D1
    P3 <-->|コピーしたタスク情報| D2
    P3 -->|タスク変更の記録| P6

    P1 -->|接続元・接続先<br/>接続選択・削除の指示| P4
    P4 -->|処理結果、選択状態| P1
    P4 <-->|接続、タスク、選択状態| D1
    P4 -->|接続変更の記録| P6

    P1 -->|検索文字列、ステータス<br/>基準タスク、最大深さ| P5
    P5 -->|表示対象タスク・接続<br/>件数、条件の状態| P1
    P5 <-->|タスク、接続、表示設定| D1

    P1 -->|取り消し・やり直しの指示| P6
    P6 -->|処理結果| P1
    P6 <-->|変更前後のスナップショット| D3
    P6 <-->|復元対象のアプリ状態| D1

    P1 -->|保存・手動復元の指示<br/>起動通知| P7
    P7 -->|保存・復元結果、エラー| P1
    P7 <-->|現在または復元済みのアプリ状態| D1
    P7 -->|検証済みJSON| D4
    D4 -->|保存済みJSON| P7
```

## レベル2ダイアグラム

### 3.0 タスクを管理する

タスクの登録・編集・移動・削除と、コピー・貼り付けを分解して示す。タスク削除時には、そのタスクを端点とする接続も同時に削除する。

```mermaid
flowchart LR
    P1[1.0 操作受付・画面描画]
    P31([3.1 入力と対象を<br/>検証する])
    P32([3.2 タスクを<br/>登録・編集・移動する])
    P33([3.3 タスクを<br/>削除する])
    P34([3.4 タスクを<br/>コピー・貼り付けする])
    P6[6.0 操作履歴管理]

    D1[(D1 実行中アプリ状態)]
    D2[(D2 コピー状態)]

    P1 -->|操作種別、入力値、対象ID、位置| P31
    D1 -->|現在キャンバス、対象タスク<br/>タスク・接続一覧| P31
    P31 -->|検証エラー| P1
    P31 -->|検証済み登録・編集・移動データ| P32
    P31 -->|検証済み削除対象| P33
    P31 -->|検証済みコピー・貼付データ| P34

    P32 -->|追加・更新したタスク<br/>解除した表示条件、選択状態| D1
    P32 -->|変更前後のタスク情報| P6
    P32 -->|処理結果| P1

    P33 -->|削除後のタスク・接続<br/>選択状態、深さ条件| D1
    P33 -->|削除タスクと付随接続の情報| P6
    P33 -->|処理結果| P1

    P34 <-->|コピー元ID、キャンバスID<br/>タイトル、説明文、ステータス| D2
    P34 -->|貼り付けたタスク、選択状態| D1
    P34 -->|貼り付け前後のタスク情報| P6
    P34 -->|処理結果| P1
```

### 4.0 接続を管理する

接続は現在のキャンバス内にある、表示中の異なる2タスク間だけに作成する。同一方向の重複と自己接続は拒否する一方、逆向きの接続と循環は許容する。

```mermaid
flowchart LR
    P1[1.0 操作受付・画面描画]
    P41([4.1 接続対象を<br/>選択する])
    P42([4.2 接続条件を<br/>検証する])
    P43([4.3 接続を<br/>作成・削除する])
    P5[5.0 表示対象の絞り込み]
    P6[6.0 操作履歴管理]
    D1[(D1 実行中アプリ状態)]

    P1 -->|接続元・接続先タスクID<br/>または削除対象接続ID| P41
    P5 -->|表示対象タスクID| P41
    D1 -->|現在キャンバス、タスク・接続一覧| P41
    P41 -->|接続元・接続先、既存接続| P42
    P42 -->|検証済み作成・削除データ| P43
    P42 -->|自己接続・重複等のエラー| P1
    P43 -->|更新した接続一覧、選択状態| D1
    P43 -->|接続変更の記録| P6
    P43 -->|処理結果| P1
```

### 5.0 表示対象を絞り込む

検索、ステータス絞り込み、深さフィルターはAND条件で併用する。深さは接続の向きを無視した最短距離で判定する。

```mermaid
flowchart LR
    P1[1.0 操作受付・画面描画]
    P51([5.1 表示条件を<br/>設定・検証する])
    P52([5.2 深さ以内の<br/>タスクIDを求める])
    P53([5.3 全条件で<br/>タスクを絞り込む])
    P54([5.4 両端が表示対象の<br/>接続を選ぶ])
    D1[(D1 実行中アプリ状態)]

    P1 -->|検索文字列、ステータス<br/>基準タスクID、最大深さ| P51
    P51 -->|検証済み表示設定| D1
    D1 -->|現在キャンバスの<br/>タスク・接続一覧| P52
    D1 -->|検索・ステータス条件| P53
    P51 -->|深さ条件| P52
    P52 -->|基準から最短距離以内の<br/>タスクID集合| P53
    D1 -->|現在キャンバスのタスク一覧| P53
    P53 -->|全条件を満たすタスク| P54
    D1 -->|現在キャンバスの接続一覧| P54
    P53 -->|表示対象タスク、件数| P1
    P54 -->|表示対象接続| P1
    P51 -->|条件エラー| P1
```

### 7.0 状態を保存・復元する

保存対象は、キャンバス、タスク、接続、現在キャンバスID、表示設定を含むAppStateである。選択状態、編集モード、コピー状態、undo・redo履歴は保存しない。

```mermaid
flowchart LR
    P1[1.0 操作受付・画面描画]
    P2[2.0 キャンバス管理]
    P71([7.1 アプリ状態を<br/>保存形式へ変換する])
    P72([7.2 保存データを<br/>検証する])
    P73([7.3 JSONを<br/>読み書きする])
    P74([7.4 AppStateを<br/>再構築する])
    D1[(D1 実行中アプリ状態)]
    D2[(D2 コピー状態)]
    D3[(D3 undo・redo履歴)]
    D4[(D4 localStorage)]

    P1 -->|保存指示| P71
    P2 -->|切り替え時の保存要求| P71
    D1 -->|現在のAppState| P71
    P71 -->|保存形式データ| P72
    P72 -->|検証済み保存データ| P73
    P73 -->|JSON| D4
    P73 -->|保存結果・書込エラー| P1
    P73 -->|保存結果| P2

    P1 -->|起動時または手動の復元指示| P73
    D4 -->|保存済みJSON| P73
    P73 -->|解析済み保存データ| P72
    P72 -->|検証済み復元データ| P74
    P74 -->|復元したAppState<br/>選択・モードの初期化| D1
    P74 -->|コピー状態の初期化| D2
    P74 -->|履歴の初期化| D3
    P74 -->|復元結果| P1
    P72 -->|形式・必須項目・型・ID参照<br/>座標値等の検証エラー| P1
    P73 -->|読込・JSON解析エラー| P1
```

## UMLクラス図との対応

| DFDの要素 | 主に対応するクラス |
|---|---|
| 1.0 操作受付・画面描画 | `EventController`、`Renderer` |
| 2.0〜4.0 各データの管理 | `Application`、`Canvas`、`Task`、`Connection` |
| 5.0 表示対象の絞り込み | `ViewSettings`、`FilterService` |
| 6.0 操作履歴管理 | `HistoryManager`、`HistoryEntry` |
| 7.0 状態の保存・復元 | `LocalStorageService` |
| D1 実行中アプリ状態 | `Application`と、それが所有する`AppState`（`Canvas`、`Task`、`Connection`、`ViewSettings`を包含） |
| D2 コピー状態 | `ClipboardState` |
| D3 undo・redo履歴 | `HistoryManager`が保持する`HistoryEntry` |
